# In this i demonstrate the use of flexbox to create the login page in which i have created two html file one for the sign in and other is for sign up.

I have created the two new html files and created one a tag in login which through which i land to the Sign up if somebody wants to add or register on it.
To access i have name the anchor - register here, through which user directly land on sign up page and in sign up html file i have created the other anchor tag which i named a sign through which if user is already sign in then it can again sign in.

To connect the both html link i have given each html files address in href of anchor tag in each html file.

# To design and arrange the elements in same line i have use the flex option.
Flex as a display can be used in the parent class only.
To define the direction of all child elements in flexbox i have used flex direction default value is column.
To increase the boldness of the font i have used weight keyword.
To move the all elements in the x axis i have used justify-content.
To move the elements in the y axis i have used align-items.
